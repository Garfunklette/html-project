# Herding Cats: Math Edition --- Math Curriculum and Adaptive Progression

**Document version:** 1.0\
**Status:** Approved design baseline\
**Primary learner:** Grade 2, approximately 7--8 years old\
**Initial focus:** Subtraction within 100, especially two-digit
subtraction with regrouping

## 1. Instructional goal

The learner will develop conceptual understanding, procedural skill, and
confidence with subtraction within 100.

The immediate target is problems such as:

``` text
  64
- 38
----
  26
```

The learner should understand that: - 64 is 6 tens and 4 ones. - 4 ones
are not enough to subtract 8 ones. - One ten can be exchanged for ten
ones. - 64 can therefore be represented as 5 tens and 14 ones. - 14 − 8
= 6 ones. - 5 tens − 3 tens = 2 tens. - The result is 26.

The game should teach the meaning of the exchange before expecting
fluent written regrouping.

## 2. Instructional principles

1.  **Concrete to visual to symbolic:** Move from manipulable blocks, to
    drawings/representations, to written numerals.
2.  **Place value language:** Prefer "exchange a ten for ten ones" over
    relying only on "borrow."
3.  **One new demand at a time:** Do not combine regrouping, unfamiliar
    wording, and large number ranges before prerequisites are stable.
4.  **Explain errors:** Use an error to choose a useful next prompt.
5.  **Practice for understanding:** Use varied examples and occasional
    explanations, not only repetitive speed drills.
6.  **Separate support from mastery:** A correct answer with a worked
    solution is not evidence of independent mastery.
7.  **Spiral review:** Continue to revisit earlier skills after new
    skills are introduced.

## 4. Detailed learning progression

### Phase A --- Place-value foundations

**Goal:** Understand two-digit numbers as tens and ones.

Examples: - 64 = 6 tens and 4 ones. - 52 = 5 tens and 2 ones. - 70 = 7
tens and 0 ones.

Activities: - Build a number using tens rods and ones. - Match a numeral
to a visual representation. - Break a number into tens and ones. -
Compare two representations of the same number.

Readiness evidence: - Correctly represents a range of two-digit
numbers. - Can identify the tens and ones in a number. - Can explain
that ten ones have the same value as one ten.

### Phase B --- Subtracting without regrouping

**Goal:** Establish confidence with subtraction where each place can be
subtracted independently.

Examples: - 64 − 30 = 34. - 64 − 4 = 60. - 68 − 25 = 43. - 75 − 32 = 43.

Activities: - Remove tens rods. - Remove individual ones. - Solve
vertical subtraction. - Match a visual action to a number sentence.

Readiness evidence: - Subtracts tens and ones accurately in varied
examples. - Understands that each digit represents a place value. - Does
not treat the digits as unrelated single-digit numbers.

### Phase C --- Understand regrouping as an exchange

**Goal:** Understand that one ten can be exchanged for ten ones without
changing the total value.

Examples: - 64 = 6 tens + 4 ones. - 64 = 5 tens + 14 ones. - 52 = 5
tens + 2 ones. - 52 = 4 tens + 12 ones.

Activities: - Drag one ten rod into an exchange area. - Animate it
becoming ten individual ones. - Compare the total before and after the
exchange. - Practice exchanges without subtracting yet.

Readiness evidence: - Can exchange one ten for ten ones. - Can state or
show that the total value stays the same. - Can identify the new tens
and ones after the exchange.

### Phase D --- One-digit subtraction requiring regrouping

**Goal:** Use the exchange to subtract a one-digit number from a
two-digit number.

Examples: - 64 − 8 = 56. - 52 − 7 = 45. - 71 − 6 = 65.

Activities: - Build the starting number. - Exchange one ten if needed. -
Remove the required ones. - Count the remaining tens and ones. - Connect
the visual result to the written equation.

Readiness evidence: - Uses the exchange appropriately. - Subtracts the
ones accurately after exchanging. - Understands why the tens count has
decreased by one.

### Phase E --- Two-digit subtraction with regrouping

**Goal:** Combine the ones exchange with subtraction of tens.

Core examples: - 64 − 38 = 26. - 52 − 27 = 25. - 73 − 46 = 27. - 81 − 35
= 46. - 92 − 58 = 34.

Activities: - Solve with base-ten blocks. - Solve using a place-value
chart. - Complete a partially filled vertical algorithm. - Solve
independently and explain the exchange. - Compare a correct and
incorrect worked example.

Readiness evidence: - Regroups accurately when required. - Subtracts the
ones and tens correctly. - Can connect the written method to the visual
exchange. - Succeeds across varied starting digits and subtrahends.

### Phase F --- Decide when regrouping is needed

**Goal:** Recognize that not every subtraction problem requires an
exchange.

Mixed examples: - 83 − 21 = 62. (No regrouping) - 83 − 27 = 56.
(Regrouping) - 75 − 32 = 43. (No regrouping) - 75 − 38 = 37.
(Regrouping)

Activities: - Predict whether an exchange is needed before solving. -
Sort problems into "exchange" and "no exchange." - Solve a mixed set
with visual support available. - Explain the decision in simple terms.

Readiness evidence: - Correctly identifies when the ones digit on top is
smaller than the ones digit being subtracted. - Does not regroup
unnecessarily. - Can solve both types accurately.

### Phase G --- Check and reason about subtraction

**Goal:** Build flexible number sense and catch errors.

Examples: - 64 − 38 = 26; check with 26 + 38 = 64. - 73 − 46 = 27; check
with 27 + 46 = 73. - 64 − ? = 26. - ? − 38 = 26.

Activities: - Use addition to check a subtraction answer. - Find a
missing subtrahend or starting number. - Identify the mistake in a
worked solution. - Explain why an answer is too large or too small.

Readiness evidence: - Uses the inverse relationship appropriately. - Can
solve simple missing-number problems. - Can identify common regrouping
mistakes.

### Phase H --- Word problems and transfer

**Goal:** Apply subtraction within 100 in simple contexts.

Example: "64 fish were in the sanctuary pond. 38 were moved to another
pond. How many fish remain?"

Activities: - Identify the quantities and what is being asked. - Choose
subtraction as the operation. - Represent the problem with objects or a
drawing. - Write and solve the number sentence. - Explain the answer in
context.

Readiness evidence: - Selects subtraction in straightforward one-step
situations. - Represents and solves the problem. - Gives an answer that
matches the context.

## 5. Problem generator requirements

The problem generator should accept explicit constraints and return both
the problem and metadata describing its mathematical structure.

Suggested parameters: - Minimum and maximum minuend. - Minimum and
maximum subtrahend. - Whether the answer must be non-negative. - Whether
regrouping is required, forbidden, or optional. - Whether the problem is
one-digit or two-digit subtraction. - Whether zeros in the ones place
are allowed. - Skill tag and difficulty label.

For the initial target: - Minuend: 10--99. - Subtrahend: 10--99. -
Answer: 0--99. - Regrouping required in the ones column. - No negative
answers. - Avoid overly repetitive number patterns.

The generator should not merely check that the final answer is correct.
It must correctly classify whether regrouping is needed and provide
valid solution steps.

### Example problem metadata

For 64 − 38:

``` js
{
  minuend: 64,
  subtrahend: 38,
  answer: 26,
  requiresRegrouping: true,
  minuendTens: 6,
  minuendOnes: 4,
  subtrahendTens: 3,
  subtrahendOnes: 8,
  regroupedTens: 5,
  regroupedOnes: 14,
  resultTens: 2,
  resultOnes: 6,
  skills: [
    'place-value',
    'regrouping',
    'two-digit-subtraction'
  ]
}
```

This is an illustrative data contract; implementation details can
evolve.

## 7. Adaptive mastery model

Track each skill independently on a five-level scale.

  Level   Label            Evidence
  ------- ---------------- ------------------------------------------------
  0       Not introduced   No practice evidence
  1       Learning         Needs a model or substantial guidance
  2       Developing       Some independent success, but inconsistent
  3       Proficient       Consistent independent success on varied items
  4       Mastered         Sustained independent success and transfer

### 7.1 Attempt evidence

For each problem attempt, record: - Skill IDs. - Whether the answer was
correct. - Attempt number. - Hint used. - Workshop opened. - Worked
solution revealed. - Visual exchange completed independently or
demonstrated. - Whether the answer was entered independently. - Problem
format and number characteristics.

Avoid storing unnecessary personal information.

### 7.2 Suggested evidence weights

Use a transparent initial heuristic rather than a complicated
statistical model:

  -----------------------------------------------------------------------
  Outcome                             Mastery evidence
  ----------------------------------- -----------------------------------
  Correct independently, no hint      Strong positive

  Correct after a small hint          Moderate positive

  Correct after using visual workshop Positive, with support noted
  independently                       

  Correct after full worked solution  Participation evidence, not
                                      independent mastery

  Incorrect, then correct             Positive recovery evidence
  independently on a fresh problem    

  Incorrect repeatedly                Evidence to reteach or revisit
                                      prerequisites
  -----------------------------------------------------------------------

Do not make one attempt decisive. Use a recent window of varied problems
and preserve older evidence for context.

### 7.3 Initial promotion guidance

These are starting heuristics to test, not fixed educational claims:

-   **Level 0 → 1:** Introduce the skill with a model and guided
    practice.
-   **Level 1 → 2:** Several supported successes across more than one
    example.
-   **Level 2 → 3:** A majority of recent varied attempts correct
    independently, with no recurring conceptual error.
-   **Level 3 → 4:** Consistent independent success across multiple
    sessions and problem formats, including a transfer example.
-   **Any level → review:** Repeated errors or a long gap can trigger a
    short review without erasing previously earned progress.

The parent should be able to select a skill manually regardless of the
suggested level.

## 8. Adaptive practice selection

At the end of a mission or practice set:

1.  Identify the current target skill.
2.  Check whether its prerequisites are stable.
3.  Review recent independent and supported attempts.
4.  Choose one of:
    -   Continue at the current level.
    -   Add visual support.
    -   Return to a prerequisite.
    -   Mix in a previously learned skill.
    -   Introduce a slightly more complex example.
5.  Present the next activity as a friendly recommendation, not a
    judgment.

Do not automatically jump from a few correct answers to the hardest
problems. Do not keep the learner on easy problems indefinitely after
clear mastery.

### Example

If the learner: - Subtracts tens confidently. - Subtracts ones
confidently. - Understands the visual exchange with help. - Struggles to
complete 64 − 38 independently.

Then the game should recommend more guided two-digit regrouping, not
repeat basic subtraction of tens.

## 10. Sample mission: The Fishpond Rescue

**Story:** A shy cat is watching the fishpond. The caretaker needs to
move some fish to another pond and count how many remain.

Mission focus: two-digit subtraction with regrouping.

Example sequence: 1. `64 − 8` --- guided exchange. 2. `52 − 7` ---
supported practice. 3. `64 − 38` --- two-digit regrouping. 4. `73 − 46`
--- transfer to a new example.

Adaptation: - If the learner struggles on problem 1, reopen the
workshop. - If problem 2 is correct with support, keep visual support
available. - If problems 3 and 4 are independently correct, record
strong evidence for the target skill. - If the learner needs a worked
example, allow mission completion through guided participation, but do
not mark the skill mastered.

## 11. Assessment and parent summary

The parent view should be brief and actionable.

Suggested information: - Recently practiced skills. - Skills that appear
comfortable. - Skills that still benefit from visual support. - Whether
answers were independent or supported. - Suggested next practice. - A
few recent examples, if useful.

Avoid grades, labels such as "bad at math," or comparisons with other
children. The purpose is to guide support, not rank the learner.

## 12. Testing requirements

### Math correctness tests

Include deterministic tests for: - Subtraction without regrouping. -
Subtraction with regrouping. - A zero in the ones place of the
minuend. - Equal ones digits. - Subtracting a multiple of ten. -
Smallest valid two-digit cases. - Non-negative result constraints. -
Correct regrouped tens and ones. - Correct result after regrouping.

Required examples: - `64 − 38 = 26`. - `52 − 27 = 25`. -
`73 − 46 = 27`. - `81 − 35 = 46`. - `92 − 58 = 34`. - `83 − 21 = 62` (no
regrouping). - `70 − 46 = 24` (regrouping from zero ones).

### Generator tests

-   Every generated problem meets its requested constraints.
-   Required-regrouping mode always produces a problem that needs
    regrouping.
-   No-regrouping mode never produces a problem that needs regrouping.
-   No negative answers when prohibited.
-   The generator avoids an excessive number of duplicates in a short
    set.

### Learning-system tests

-   A worked solution does not count as independent mastery.
-   A hint-assisted correct answer is recorded distinctly.
-   Repeated errors can trigger prerequisite review.
-   Mastery is tracked separately by skill.
-   A single mistake does not erase established mastery.
-   Parent overrides are respected.

### Usability tests

-   A learner can complete the workshop using a mouse.
-   Answer entry works with a keyboard.
-   Instructions remain understandable without sound.
-   The game can be paused or exited without losing progress.

## 13. Initial release curriculum scope

For the first playable version, implement only:

1.  Place-value representation of tens and ones.
2.  Exchange one ten for ten ones.
3.  One-digit subtraction requiring regrouping.
4.  Two-digit subtraction requiring regrouping in the ones column.
5.  Hints and worked examples.
6.  Basic attempt evidence for independent versus supported success.

Do not implement all word-problem formats, all mastery levels, or a
sophisticated adaptive algorithm in the first iteration. First validate
that the visual exchange is understandable and that the learner can use
it to solve examples such as `64 − 38`.

**Guiding instructional principle:** The goal is not to make a child
faster at borrowing. The goal is to help the child understand that
numbers can be regrouped without changing their value.
